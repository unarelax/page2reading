纸质阅读工具

Page2Reading

网上的长文，变成你桌上那一叠可以装订的纸。

打开一篇英文技术博客，点一下 Chrome 扩展。关掉页面也没关系。过一会儿，桌面上会多出排好版的 PDF——可以是原文，也可以是一段英文一段中文的对照稿。周末打印、装订，每天当报纸看一篇。

你只需要点其中一个

导出原文 PDF 适合已经读得懂、只想要干净打印稿
导出中英对照 PDF 适合想跟着讲解把文章看下来

印出来长什么样

  • A4，适合长时间看，不是网页那种窄栏。
  • 文章正文从第一页就开始，不拿标题栏挡你。
  • 写完才看到来源：标题、作者、日期、链接，旁边一个二维码，手机扫就能回原文。
  • 图会印在 PDF 里。不另存一堆图片文件。

文件会出现在哪

默认在电脑桌面的 Page2Reading 文件夹，按当天日期分开放：

Page2Reading/ └── 20260911/ ├── or-文章标题.md ├── or-文章标题.pdf ├── tr-文章标题.md └── tr-文章标题.pdf

or- 是原文，tr- 是对照。只导出原文时，不会有 tr- 那两个文件。

飞书表格里会记：标题、链接、作者、日期，以及这两个文件在电脑上的路径。表格打不开文件本身，路径是给你找打印稿用的。

第一次怎么接上

  1. 电脑要是 Mac，装着 Google Chrome 和 Node.js 20 以上。
  2. 在项目里复制 .env.example 为 .env，填上 DeepSeek 的 API Key。飞书可以以后再填。
  3. 终端运行 npm install，再 npm run build:extension，再 npm run serve。
  4. 另开终端运行 npm run cli -- token，复制那一串令牌。
  5. Chrome 打开扩展页，打开开发者模式，加载项目里的 apps/extension/dist。
  6. 扩展选项里填服务地址 http://127.0.0.1:17321 和刚才的令牌。

以后每次用之前，本机服务要在跑。不想每次手开，可以运行一次 bash scripts/install-launchagent.sh，开机后会自己起来。

卡住了先看这里

你看到什么多半是先试什么
提示本地服务未启动 没开 npm run serve 开服务后再点一次
提示未配置令牌 / unauthorized 选项页令牌不对 重新 npm run cli -- token 贴进去
扩展说已经导出过 同一链接同一模式做过了 换对照/原文，或让开发者强制重跑
桌面有 PDF，飞书没有 表格列名不齐或没填飞书密钥 七个列都建成「文本」后再重试任务
PDF 里图是空的 出 PDF 时图没加载完 联网后重跑这一篇
这不是网盘，也不是在线翻译网站。文章和密钥都留在你这台电脑上。更细的安装步骤以仓库 README 为准。
